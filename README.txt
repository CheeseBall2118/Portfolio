【如何换图片】
把你的图片放入 images 文件夹，并按以下文件名命名：
project01-cover.jpg = 项目01封面
project01-01.jpg / 02 / 03 = 项目01案例图
依此类推到 project04。

如果不想改文件名，也可以直接打开 index.html，用搜索替换图片文件名。

【如何编辑文字】
用 VS Code、Cursor、Sublime Text 或记事本打开 index.html。
搜索项目标题、MY ACTION、RESULT 等文字直接修改即可。

【发布】
可上传整个文件夹到 GitHub，再连接 Vercel，即可获得公开网页链接。
